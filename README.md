# Fisherman's Village - Game Demo

**Fisherman's Village** is a first-person survival horror experience developed using **Unity 6000**, inspired by the Lovecraftian classic *The Shadow over Innsmouth*. This project was created as part of the COMP3000 coursework for the Game Development module at Plymouth University.

---

## Project Overview

- **Game Title**: Fisherman's Village  
- **Genre**: First-Person Survival Horror  
- **Platform**: PC (Windows)  
- **Engine**: Unity 6000  
- **Current Version**: Game Demo v0.02  

The player explores an eerie, abandoned fishing village enveloped by fog and mystery. Navigate hostile environments, survive enemy encounters, manage limited resources, and uncover dark secrets hidden beneath the surface.

---

## Game Features

- **Immersive Atmosphere**: Dynamic lighting, dense fog, ambient soundscapes.
- **Interactive Environment**: Objects can be picked up, examined, and used to solve puzzles.
- **Inventory System**: Collect, manage, and strategically use essential items.
- **Enemy AI**: Basic enemy patrol, chase, and attack behaviors.
- **Combat Mechanics**: Limited firearms and ammo, emphasizing survival over direct combat.
- **Environmental Storytelling**: Lore-rich environment based on Lovecraftian themes.

## Installation & Setup

1. **Clone or Download** this repository.

```bash
git clone [https://github.com/yourusername/your-repository.git](https://github.com/ReHolo/Fisherman-s-village-for-COMP-3000.git)
```

2. **Open** the project using **Unity 6000 or newer**.
3. **Navigate** to the folder `Assets/Horror FPS KIT/HFPS Assets/Content/Scenes`.
4. **Open** the main game scene file (`MainMenu.unity`).
5. **Run** the game by clicking the Unity Play button.
